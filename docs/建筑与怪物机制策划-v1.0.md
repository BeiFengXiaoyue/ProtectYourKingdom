## 2. 建筑机制策划

### 2.1 三类塔定位与克制关系



| 塔  | 核心定位              | 克制         | 弱势            |
| -- | ----------------- | ---------- | ------------- |
| 箭塔 | 单体高速物理，DPS 稳定，造价低 | 快速敌人、低血单位  | 重甲（伤害低、物理减伤）  |
| 炮塔 | 范围溅射，慢攻速高爆发       | 重甲、密集群体    | 快速（溅射难命中、攻速慢） |
| 兵营 | 生成士兵阻挡路径，拖延时间     | Boss、单体高威胁 | 范围伤害敌人、士兵被清场  |

**核心克制规则：**



* 重甲敌人拥有 **物理减伤 30%**（箭塔伤害 ×0.7）✅ 已确认｜⚠️ **现状：未实现**（`Arrow.onHit`/`Bomb.onHit` 全额扣血，无护甲概念）

* 炮塔拥有 **破甲**（对重甲伤害 +30%，无视物理减伤）｜⚠️ **现状：未实现**

* 快速敌人速度快，考验塔的攻击间隔（DPS 而非单发伤害）

### 3.2 Boss 技能设计

对接 BossEnemy 类注释中已规划的机制：



| 技能 | 触发条件      | 效果                       | 实现建议                                                      |
| -- | --------- | ------------------------ | --------------------------------------------------------- |

### 3.4 难度曲线说明



* **波次差异**：仅通过**出怪种类与数量**（及出场间隔）体现难度变化；敌人属性（HP / 速度 / 赏金）为**固定值，不随波次递增**（已决定不做递增）

* **第 3 波**（快速出现）：第一个小拐点，玩家需要第 2 座箭塔

* **第 5 波**（重甲出现）：核心拐点，箭塔打重甲伤害 -30%，玩家必须建炮塔或 3 座以上箭塔集火

* **第 7 波**（重甲潮）：纯箭塔阵容几乎必漏，强制炮塔

* **第 10 波**（Boss）：需要兵营阻挡（拖延 Boss 走位）+ 炮塔爆发（打重甲 / Boss）+ 箭塔清召唤小怪

## 4. 平衡验证

路径总长度约 1120 像素（6 个拐点连线），敌人走完全程时间 = 1120 / 速度。



| 敌人          | 走完全程时间 | 单座箭塔击杀时间        | 结论              |
| ----------- | ------ | --------------- | --------------- |
| 普通          | 18.7 秒 | 2.4 秒           | 轻松              |
| 快速          | 9.3 秒  | 1.5 秒           | 轻松（但多只同时来会漏）    |
| 重甲（箭塔 -30%） | 32 秒   | 10.5 秒          | 能拦住但紧张，2 只同时来必漏 |
| 重甲（炮塔 +30%） | 32 秒   | 5.1 秒           | 炮塔克制明显          |
| Boss        | 28 秒   | 3 座满级箭塔约 12.5 秒 | 紧张，需兵营拖延 + 炮塔输出 |

**关键结论：**



* 单座箭塔能处理普通和快速，但面对重甲效率骤降

* 炮塔对重甲的击杀时间是箭塔的一半，体现克制

* Boss 战必须多类型塔配合，单一塔型无法通关
