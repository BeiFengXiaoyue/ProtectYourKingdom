# 敌人动作帧序列候选清单（供动画工具标注用）

> 编制：李贤宇（E）｜日期：2026-09-09
> 素材库编号规则：同一动画的帧按**同奇偶、步长 2** 连续存放（奇数链/偶数链各一份，互为镜像朝向）。
> 本清单按"奇数链"标注；若工具需要镜像朝向，取对应偶数编号（+1）即可。
> 通用约定：行走动画取循环段；死亡可直接复用白烟帧，或用渐隐替代。
