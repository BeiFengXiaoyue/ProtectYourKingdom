# 音效扩展方法说明（交互侧 D 对接用）

> 编制：李贤宇（E：素材与音效负责人）｜日期：2026-09-09
> 适用版本：dev（含 `util/audio/SoundManager` 后）

## 一、怎么拿到 SoundManager

`SoundManager` 是单例，**任何类直接调用即可，不需要注入或传递**：

```java
import com.kingdom.game.util.audio.SoundManager;

SoundManager.getInstance().onLifeLost();      // 例：漏怪时
SoundManager.getInstance().onGoldInsufficient(); // 例：金币不足时
```

（Main 已把它注入 controller 的 5 个标准接口，走接口的音效——波次/塔三连/战斗/胜负——交互侧**不用管**，事件到了自动响。）

## 二、扩展方法清单（供交互侧调用）

| 方法 | 触发时机 | 建议调用点 | 音效 |
| :--- | :--- | :--- | :--- |
| `void onLifeLost()` | 敌人到达终点、生命 -1 | `IStatusObserver` 收到生命减少的回调处（判断新生命 < 旧生命即调用） | `life_lost.wav`（失败警报音） |
| `void onGoldInsufficient()` | 建塔/升级因金币不足失败 | `ITowerBuilder.placeTower(...)` 返回 `false` 且收到"金币不足"推送后调用 | `gold_insufficient.wav`（纸张翻动提示音） |

调用示例（伪代码）：

```java
// 生命变化推送处
public void onLivesChanged(int oldLives, int newLives) {
    if (newLives < oldLives) {
        SoundManager.getInstance().onLifeLost();
    }
}

// 建塔失败推送处
public void onPlaceTowerFailed(String reason) {
    if (reason.contains("金币")) {
        SoundManager.getInstance().onGoldInsufficient();
    }
}
```

> 两个方法内部自带防抖，重复触发不会叠音；播不出声（文件缺失）也只是静默，不影响任何逻辑。

## 三、内置节流阀说明（防吵机制）

战斗类音效自带**最小播放间隔**，间隔内重复触发直接丢弃：

| 音效 | 最小间隔 |
| :--- | :--- |
| 单位死亡（随机 4 选 1 + 随机变调） | 150ms |
| 近战攻击 | 150ms |
| 箭矢发射 / 命中 | 60ms |
| 炸弹爆炸 | 100ms |
| 单位出场 | 300ms |

也就是说：怪物扎堆死亡时，死亡音**最多每 150ms 响一次**（约每秒 6 次上限，且每次音调略有差异），不会出现一波怪同时死导致的爆音刷屏。波次/塔操作/胜负属于一次性事件，不节流。

如果联调时觉得某个音效还是太密/太稀，直接找 E 改 `SoundManager` 里对应的间隔数字即可，调用方不用动。

| 事件 | 音效文件 | 触发方 |
| :--- | :--- | :--- |
| 波次开始 | wave_start.wav | controller（自动） |

| 投射物发射（箭） | arrow_release.wav | controller→实体（自动） |
| 投射物命中（箭/弹） | arrow_hit.wav / bomb_hit.wav | controller→实体（自动） |
| 近战攻击 | melee_attack.wav | controller→实体（自动） |
| 单位死亡 | die_1~4.wav 随机 | controller→实体（自动） |
| Boss 震地 | boss_stomp.wav | 实体调用（自动） |
| 士兵出场 | unit_spawn.wav | controller（自动）——`GameController.addAlly` **已接线**（注入事件通道后调 `unitSound.onUnitSpawned`） |

| **漏怪扣生命** | life_lost.wav | **交互侧调用 `onLifeLost()`** |
| **金币不足** | gold_insufficient.wav | **交互侧调用 `onGoldInsufficient()`** |
